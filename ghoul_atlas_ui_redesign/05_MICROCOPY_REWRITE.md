# 05 — Microcopy: menos frase de efeito, mais informação

## Regras editoriais
1. Título identifica objeto, processo ou ação.
2. Subtítulo acrescenta uma informação que o título não contém; não apenas metáfora.
3. Usar terminologia do universo sem fingir validação oficial.
4. Cada informação tem um lugar: nome/estado no palco; detalhes no inspector; bibliografia em Fontes.
5. Evitar marcadores e títulos de ficção burocrática repetitivos (`ESTUDO / 001` em todas as seções).

| Antes | Depois | Motivo |
|---|---|---|
| `O que nos torna diferentes?` | `Espécime 001 · Anatomia ghoul` | Contexto direto |
| `O corpo como mapa.` | `Estruturas anatômicas` | Diz o que a lista oferece |
| `Matéria em movimento.` | `Rinkaku · Manifestação` | Nomeia fenômeno observado |
| `Uma corrente. Muitas histórias.` | `Sistema vascular` | Seção inequívoca |
| `Por dentro da corrente.` | `Transporte de células RC` | Identifica experiência |
| `Explore. Questione. Confira a evidência.` | `Controles do observatório` | Ajuda é ferramenta, não manifesto |
| `Ambiente de investigação` | `Atlas / Espécime 001` | Breadcrumb funcional |
| `ESTUDO / 001` (permanente) | `Espécime 001` no contexto; ID completo na ficha | Reduz ruído |
| `Evidência verificada` (toggle) | `Somente afirmações com fonte verificada` | Regra explícita, alcance claro |
| `Superfície corporal` | `Pele · superfície` | Mais específico quando apropriado |
| `PROXY / CONCEPTUAL MODEL` repetido | `Modelo conceitual` + link `Sobre a representação` | Honestidade sem poluição |
| `Manifestar` isolado | `Simular manifestação` | Significado inequívoco |
| `Modo de movimento` | `Simulação · Rinkaku` | Menos tecnicismo vazio |
| `Lúmen vascular` (quando cabeçalho) | `Interior do vaso` / ficha `Lúmen vascular` | Linguagem gradual |
| `Voltar ao espécime` | `Voltar ao Corpo` | Ação explícita |

## Exemplos prontos
### Vitrine
- Título: `Atlas anatômico ghoul`
- Descrição: `Explore estruturas e processos do universo Tokyo Ghoul em modelos 3D interativos. Cada hipótese visual é identificada e acompanhada de fontes.`
- CTAs: `Abrir observatório` / `Ver estudos`
- Cards: `Anatomia do ghoul`, `Manifestação Rinkaku`, `Transporte de células RC`.

### Ficha do kakuhou
- Nome: `Kakuhou · Rinkaku`
- Categoria: `Órgão associado às células RC`
- Localização: `Região lombar · localização aproximada no modelo`
- Ação: `Simular manifestação`
- Aviso: `Morfologia interna interpretativa; não documentada em detalhe pelo cânone.`

### Ficha celular
- Nome: `Célula RC · representação conceitual`
- Ação: `Seguir célula` / `Inspecionar célula` / `Voltar ao fluxo`
- Aviso: `Forma, tamanho e transporte nesta cena são escolhas didáticas, não medidas canônicas.`

### Ajuda
- Título: `Controles e navegação`
- Corpo: `Arraste para girar. Role para aproximar. Selecione uma estrutura para abrir sua ficha. Pressione Esc para retornar ao nível anterior.`

## O que não fazer
Não substituir os slogans antigos por novos slogans sombrios (`O sangue revela a verdade`, `Anatomia do impossível`, `Entre carne e silêncio`). O mistério deve surgir do objeto e das evidências, não de copy teatral.
